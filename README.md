# Plant Disease Prediction Model 🌿

Welcome to  **PlantShield** — a deep learning/machine learning - powered web application designed to help farmers, gardeners, and researchers quickly identify plant diseases from leaf images.

## 🌿 Overview
This system leverages deep learning to recognize a variety of plant diseases and distinguish them from healthy conditions. By analyzing uploaded images of plant leaves, the model provides real-time diagnosis and insights, making it an invaluable tool for early intervention and crop protection.

---

## 🔍 How It Works

1. **Upload an Image**: Users upload a picture of a plant leaf through the interface.
2. **Image Analysis**: The image is preprocessed and analyzed using a pre-trained deep learning model.
3. **Disease Detection**: The model predicts the disease category or confirms the plant is healthy.
4. **Results**: A diagnosis is displayed along with suggested treatments or preventive measures.

---

## ✨ Features

- ✅ **High Accuracy**: Model accuracy exceeds 90% on test data.
- 🖼️ **User-Friendly Interface**: Intuitive and clean UI built with Streamlit.
- ⚡ **Fast Inference**: Quick image processing for on-the-spot decision-making.

## 📂 Dataset

The dataset used includes images of various plant species and disease types. It has been divided into:

- train 
- test  
- valid  

To use the model, ensure these folders are extracted and included in your project directory. The dataset can be found at the appropriate source 
https://www.kaggle.com/datasets/vipoooool/new-plant-diseases-dataset
